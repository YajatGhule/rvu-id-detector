About this project

The RVU ID Card Detector checks whether each person in the camera view is wearing the RVU ID card on its lanyard. It is a Web Technology course project. The web pages are plain HTML and CSS, and the detection runs in a Python program on the same computer.

How the detector works

1. Finding people and their pose

A neural network called YOLO11n-pose finds every person in each frame. For each person it gives a box around the body and 17 body points, such as the eyes, shoulders and hips.

2. Keeping track of each person

A tracker called ByteTrack gives each person a number that stays the same from frame to frame. This lets the detector follow one person over time instead of treating every frame as new.

3. Finding the torso

From the shoulders and hips the program cuts out the torso, the area from the neck to the waist, where a lanyard normally hangs. If the face or torso cannot be seen, for example when a person has their back turned, the person is marked UNSURE. UNSURE is not counted as a violation.

4. Checking the band colour

The program counts the pixels in the torso area that match the lanyard band colour you set in Settings. Each colour is compared in a way that is close to how people see colour. The tolerance setting decides how close a colour must be. This check also rejects lanyards of other colours.

5. Combining and smoothing the result

The colour score is combined with the detector confidence to give one score between 0 and 1. The program looks at the last few frames for each person and takes a vote. Two thresholds, one for WEARING and one for NOT WEARING, stop the box from flickering between colours when the score is near the limit.

6. Showing and logging the result

Green means WEARING, red means NOT WEARING and grey means UNSURE. If a person stays NOT WEARING for the number of seconds set in Settings, the program saves one cropped picture and a row in a local database. The History page lists these rows, and they can be exported as a CSV file or deleted.

Privacy

Everything stays on this computer. Video frames and snapshots are not uploaded to any server. The web pages talk only to the detector running on 127.0.0.1, which means this computer only.

Limits

The detector is a student prototype. It can make mistakes when lighting is poor, when the lanyard is hidden under clothing, or when a similar colour is worn. Results should be checked by a person.
