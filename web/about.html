About this project

This website checks if a student is wearing the RVU ID card. It works with a webcam, a photo or a video.

How it works

  1. The program finds every person in the picture.
  2. Each person gets a number so that the program can follow them.
  3. It looks at the chest of the person for the band of the ID card.
  4. It checks a few pictures one after another so that the answer does not keep changing.
  5. If a student has no ID card for a few seconds, a photo is saved in History.

What is used

Part Made with
Pages HTML and CSS only (no JavaScript)
Background program Python, FastAPI, OpenCV
Finding people YOLO11 model
History table SQLite

Privacy

Nothing is sent to the internet. There is no face recognition.
